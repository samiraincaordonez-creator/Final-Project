# Final-Project
Camila vive en Perú y planea viajar de vacaciones entre enero y marzo. Le interesa visitar Japón, pero sabe que es una zona altamente sísmica y le preocupa la ocurrencia de terremotos. Para viajar más tranquila, quiere saber en qué mes del verano el riesgo sísmico es menor usando datos de 2023 a 2025.
